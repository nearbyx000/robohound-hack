# Мама, я робприк · Hackathon Go1 T2

Safety Block для режима MuJoCo Lowlevel. Вход — `/lowcmd_bare`, выход —
`/lowcmd`. Стартовая поза сверяется с `/lowstate`, тайм-аут считается по
`/clock`. В протоколе `ping` заявлено только T2.

## Сборка и проверка образа

Откройте терминал в папке с Dockerfile. Для сборки нужен интернет. В Docker
собираются ROS 2-интерфейсы Unitree, устанавливается MuJoCo 3.3.7 и запускаются
проверки модели и логики. После сборки образ может запускаться автономно.

```cmd
docker buildx build --platform linux/amd64 --load -t robprik-go1:t2 .
docker run --rm --platform linux/amd64 --network none robprik-go1:t2 ping
```

Ожидаемый JSON

```json
{"protocol_version":"1.0","supported_tasks":["T2"],"self_trained_rl":false,"preferred_speed_mps":null}
```

Быстрая проверка логики на хосте без ROS и MuJoCo выполняется командой
`python3 test_safety.py`. В Windows можно использовать `py -3 test_safety.py`.

## Проверка с публичным симулятором

Из каталога официального симулятора в Linux или WSL с Docker запустите:

```sh
python3 run_local.py --task T2 --sim-image registry.cookcloud.ru/go1-hackathon-remote-stage/go1-sim:v1.0 --participant-image robprik-go1:t2 --headless --logs
```

Запускатель поднимает ROS 2-связь с Simulator. Для проверки поведения подайте
`unitree_go/msg/LowCmd` в `/lowcmd_bare` и наблюдайте `/lowcmd` и `/clock`.
Начните с цели вблизи текущей позы, затем проверьте скачок цели, опасную позу и
паузу во входном потоке. Считайте частоту и разрывы по `/clock`. Judge
оценивает поведение на отдельных сценариях.

## Что проверяет узел

- Валидирует числовые поля всей команды. Для активных приводов принимает
  режим 10 и неотрицательные коэффициенты PD-регулятора.
- Ограничивает позицию по каждому суставу и изменение цели за публикацию до
  5°. Проверяет начало, конец и промежуточные точки с шагом максимум 0,1°.
- Использует 655 пар из таблицы организаторов. Ограничивающие сферы отсекают
  заведомо раздельные геометрии. Для остальных считается глубина проникновения
  MuJoCo. Порог внутри узла составляет 0,95 мм с запасом до судейского 1 мм.
- При опасном переходе сохраняет последнюю безопасную цель. При отсутствии
  принятой команды в течение 0,45 с симуляционного времени обнуляет
  целевую скорость и добавочный момент и продолжает публиковать удержание.
  Таймер запланирован на 125 Гц по монотонному времени.
- Пока нет первой безопасной телеметрии, стартует с проверенной позы
  `home` по истечении 0,2 с. Входные команды обрабатываются после получения
  `/clock`.
